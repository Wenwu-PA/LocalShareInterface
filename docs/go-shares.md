# Временные ссылки и телефон — Go

## Создание и отзыв

В разделе «Файлы» откройте меню «•••» у файла или папки и выберите «Временная
ссылка». Укажите срок (1–720 часов в интерфейсе), пароль от 8 до 256 байт или
оставьте поле пустым; лимит 0 означает отсутствие ограничения числа скачиваний.
Папка скачивается ZIP-потоком. Гость может только скачивать выбранный объект.

Сохраните адрес сразу: сервер хранит SHA-256 токена, поэтому повторно показать
полную ссылку нельзя. Под очередью есть панель «Временные ссылки»: активные или
все записи, страницы по 25, обновление и отзыв в один клик. Обычный пользователь
видит свои ссылки, администратор — всех. Максимум 1000 записей на владельца;
при создании удаляются его записи, истёкшие более 30 дней назад.

Создание требует права записи на весь объект. При каждом скачивании заново
проверяются существование владельца, его текущая роль и права чтения всего дерева.
Если хотя бы один потомок недоступен, папка не выдаётся. Общий корень публиковать
нельзя. Ссылка относится к пути, а не снимку: замена или изменение содержимого
по этому пути изменит доступный гостю файл. Переименование может сделать ссылку
недействующей; новый объект на старом пути станет доступен через неё.

## Счётчик и ограничения

Сначала гость получает одноразовую кнопку скачивания, действующую 60 секунд.
Её создание, просмотр страницы и HEAD не расходуют лимит; HEAD скачивания
возвращает 405. GET атомарно расходует одну попытку перед началом передачи,
включая Range, последующий обрыв или ошибку чтения. Две одновременные попытки
не могут превысить лимит. Для повторного GET нужна новая кнопка. Параметры пути
и inline от гостя игнорируются. Условные заголовки не превращают попытку в 304.

Отзыв/истечение запрещает новые скачивания, в том числе по уже выданной кнопке;
начатая передача не прерывается. Одновременно доступны две гостевые передачи; запись каждого блока ограничена
30 секундами ожидания клиента.
В памяти хранится максимум 1024 краткоживущих кнопки. После перезапуска кнопки
нужно получить заново; сами ссылки и счётчики сохраняются в SQLite.

Пароли хешируются Argon2id. На один IP разрешено 10 ошибочных попыток за 15 минут;
вычисления пароля ограничены общей очередью авторизации. Таблица попыток ограничена
10 000 IP за окно. Токены и пароли не включаются в аудит: в нём сохраняются ID
ссылки при создании и отзыве. Секретные адреса не пишутся при обработке panic.
Скачивания отмечаются как гостевые в истории с ID ссылки и именем её владельца,
размером, временем и статусом. Имя владельца не означает, что скачивал он сам.

## Телефон и QR

«Подключить телефон» создаёт QR для страницы файлов, требующей входа. В диалоге
создания ссылки QR открывает только гостевой объект. Код строится локально
библиотекой `qrcode-generator` 2.0.4 (MIT), без передачи адреса сторонним сервисам.
Лицензия поставляется в `/licenses/qrcode-generator-MIT.txt`.

В поле адреса выберите HTTPS-адрес LAN-интерфейса из подсказок либо введите
проверенное имя сервера. `localhost` и `127.*` относятся к самому телефону, поэтому
для него непригодны. Если Go слушает только loopback, измените `server.host` в
`config.go.yaml` на `0.0.0.0` и перезапустите сервер. Этот параметр открывает
прослушивание всех IPv4-интерфейсов; ограничьте доступ нужной сетью в брандмауэре.
Телефон должен доверять сертификату, содержащему используемый IP/имя в SAN.
QR не исправляет доверие к сертификату и не включает внешний доступ.

## API

| Метод и путь | Назначение |
|---|---|
| GET /api/shares | Свои ссылки; администратор видит все, до 1000 |
| POST /api/shares | Создание: path, ttl_seconds (60–2592000), password, max_downloads (0–1000000) |
| DELETE /api/shares/{id} | Отзыв владельцем или администратором |
| GET /api/connection | Сессия: подходящие адреса интерфейсов и loopback_only |
| GET /api/guest/{token} | Публичные сведения; имя защищённого объекта скрыто |
| POST /api/guest/{token}/ticket | password; ответ с одноразовым относительным URL |
| GET /api/guest-download/{ticket} | Скачивание файла или ZIP; без учётной записи |
| GET /s/{token} | Гостевая страница |

Изменяющие запросы требуют JSON, cookie и `X-CSRF-Token`. Гость получает CSRF
через GET `/api/status`; обычная сессия ему не нужна. Список ссылок не содержит
исходные токены и хеши паролей. Передавайте адрес и пароль по отдельным каналам.

## Проверено

```powershell
go test ./...
node --test web/src/share-url.test.js
.\build.ps1
.venv\Scripts\python.exe scripts/verify_go_shares.py
```

В текущем окружении Go запускается по пути portable SDK; остальные команды
выполнены из корня проекта. Проверены файл/ZIP, пароль и перебор, конкурентный
лимит, повтор кнопки, HEAD, отзыв, истечение, права владельца и потомков,
обновление SQLite с версии 5 до 6, сохранение ссылок/лимита/сессии после полного
перезапуска, мобильная компоновка и отображение QR без ошибок JS.
Сканирование реальным телефоном и HTTPS по физической LAN пока не проверены.
