# Локализация Go-интерфейса

Русский — единственный включённый язык. Основа для следующих локалей находится
в `web/src/i18n/`: `ru.js` содержит плоский словарь, `index.js` — переводчик `t`,
`defaultLocale` и `supportedLocales`. В словарь перенесены основная навигация,
подзаголовки страниц, названия карточек, состояния проверок и действия аудита.
Формы, сообщения backend и большая часть подробных экранов пока содержат русский
текст непосредственно в коде. Это инфраструктура локализации, а не готовый
многоязычный интерфейс; переключателя языка пока нет.

## Добавление строк

Добавьте устойчивый ключ в `ru.js` и используйте его в компоненте:

```js
import {t} from './i18n/index.js';
const label = t('nav.files');
```

Для каталогов доступны текстовые подстановки `{name}`. Значения вставляются
однократно, без интерпретации HTML; результат следует передавать в текстовый узел
Preact. Не используйте его в `dangerouslySetInnerHTML`. Неизвестный ключ возвращает
сам ключ, отсутствующий перевод — русскую строку. Унаследованные свойства объектов
не используются как переводы или параметры.

## Добавление другого языка

1. Создайте `web/src/i18n/<язык>.js` с теми же ключами.
2. Зарегистрируйте каталог в `createTranslator({ru, ...})` и `supportedLocales`.
3. Передавайте код языка третьим аргументом `t(key, values, locale)`. Сейчас
   интерфейс вызывает `t` с русским языком по умолчанию.
4. Прежде чем включать выбор языка, перенесите остальные строки форм и экранов,
   сопоставьте серверные коды ошибок переводам, обновите форматирование дат и
   `document.documentElement.lang`. Массивы меню/меток сейчас вычисляются при
   загрузке модуля; для смены языка без перезагрузки их нужно вычислять при рендере.
5. Проверьте длинные подписи, мобильную ширину и доступные имена элементов.

Проверки из корня репозитория:

```powershell
node --test web/src/*.test.js
.\build.ps1
.venv\Scripts\python.exe scripts/verify_go_ui.py
```

Тесты переводчика проверяют русский каталог, резервный язык, добавление каталога,
подстановки и отсутствие обращения к прототипам. Браузерная проверка подтверждает,
что русский интерфейс сохраняет навигацию и рабочие подписи после переноса строк.
