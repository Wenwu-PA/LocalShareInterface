# Производительность новой Go-версии

Windows 11, Go 1.27.2, amd64, CGO выключен, `-trimpath -ldflags "-s -w"`.
Дата: 9 октября 2026. Все значения — реальные локальные измерения; МБ = 1 000 000 байт.

## Каркас до подключения мониторов

Измерение после создания администратора, 20 секунд простоя, 0 мониторов:

| Показатель | Результат | Цель |
|---|---:|---:|
| Бинарник с минимальным frontend | 12 758 016 байт | ≤25 000 000 |
| Working Set, пик за окно | 43 577 344 байт | ≤60 000 000 |
| Private Bytes, пик за окно | 73 838 592 байт | Отдельная диагностическая метрика |
| CPU процесса / одно ядро | 0,000% | <1% |
| Мониторы | 0 | Приёмка требует 50 / 20 с |

Working Set — резидентная физическая память. Private Bytes включает выделенную
процессу память, не обязательно находящуюся в RAM. По этой второй метрике 60 МБ
пока не достигнуты. Ограничение Go heap 40 МиБ не гарантирует лимит всей памяти ОС.
Параллельные вычисления Argon2 ограничены одним запросом.

Эти результаты относятся только к каркасу. Приёмка бюджета при 50 мониторах не
проведена, так как планировщик ещё не реализован. Прогон 100 мониторов / 20 с,
24 часа, 20+ ГиБ и 60 fps ещё не выполнен. Нельзя считать их пройденными по данным
короткого запуска.

Замер памяти сделан перед добавлением текстов лицензий и последней правкой SSE;

сборки; сервер сейчас отдаёт статику без HTTP-сжатия. Несжатые HTML/CSS/JS также
укладываются в 150 КБ. 20 снимков проверены на размеры, темы и отсутствие выхода
страницы за ширину viewport. FPS, CLS и таблицы на 1000 строк ещё не измерены.

## Первые нагрузочные проверки мониторинга, 10 октября

Цели — локальный HTTP-сервер с реальными успешными ответами. Перед нагрузкой проверены
ответ 503, порог двух ошибок, создание инцидента и его закрытие после возврата 200.

| Проверки / интервал | Окно измерения | Working Set peak | Private Bytes peak | CPU / одно ядро |
|---|---:|---:|---:|---:|
| 50 / 20 с | 45 с | 32 579 584 | 62 255 104 | 0,035% |
| 100 / 20 с | 45 с | 35 676 160 | 65 720 320 | 0,208% |

Физическая RAM и CPU укладываются в краткосрочный бюджет для этих HTTP-целей.
Private Bytes остаётся выше 60 МБ. ICMP с запуском системного процесса, медленные
внешние HTTP-цели и длительное накопление БД могут дать другие результаты.
Это не 24-часовое испытание и не подтверждение отсутствия утечек.

После добавления мониторинга бинарник: 13 789 696 байт; HTML/CSS/JS без шрифтов:
23 013 байт gzip. Первый setup-экран в локальном Chromium: 114 мс.

```powershell

.venv\Scripts\python.exe scripts/verify_go_monitors.py --monitors 100 --seconds 45
```

## Повторение smoke

Соберите приложение, затем из корня проекта запустите Python-скрипт разработчика
(нужен psutil из существующей dev-среды; для запуска самого приложения Python не нужен):

```powershell
.venv\Scripts\python.exe scripts/verify_go.py --seconds 20
```

Скрипт создаёт временные конфигурацию, сертификат, SQLite и учётную запись; проверяет
HTTPS, сессию и восстановление после принудительной остановки. Он не измеряет
graceful shutdown: принудительная остановка здесь намеренная.
