# Журнал изменений

Формат основан на Keep a Changelog; версии следуют SemVer.

## [Unreleased]

### Переход на Go

- Добавлены выбор загруженных файлов и снятие выбора для ZIP, ограничение в
  1000 объектов и сообщение при превышении допустимого объёма списка имён.
- После обновления списка удаляются отметки отсутствующих в нём объектов.

- Добавлен выбор направления сортировки файлов; папки остаются первыми.
  Браузерный тест проверяет оба направления по размеру.

- Вид файлов сохраняется в браузере отдельно для каждой учётной записи.
  Проверено восстановление списка и плиток после перезагрузки.

- Добавлен виртуализированный плиточный вид файлов с адаптивными колонками.
  Проверены переключение и прокрутка 1104 объектов на desktop/mobile.

- Добавлен предпросмотр текста (до 64 КиБ), изображений и видео без новых зависимостей.
  HTML отображается как текст; браузерный тест проверяет ограничение объёма.

- Добавлена форма настройки квот, резерва диска, корзины и срока докачки.
  Проверены сохранение после перезагрузки и отклонение недопустимого резерва.

- Добавлены файловый индекс, папки, поиск, виртуализированный список, потоковые
  загрузки с докачкой/SHA-256, Range, ZIP, копирование, перемещение и корзина.
- Добавлены квоты, наследуемые права, журнал восстановления и очистка временных
  данных. Закрыт обход прав через регистр имени каталога в Windows.
- Добавлены файловые API/модульные тесты и браузерный прогон на 1104 объектах.
- Пройдена передача 20 ГиБ с принудительным перезапуском, докачкой и сравнением
  SHA-256 после полного скачивания; записаны отдельные показатели working set и Private Bytes.


- Добавлены ограниченное ICMP/ARP/mDNS-обнаружение IPv4-устройств, расписание,
  отмена, имена/значки, история присутствия и уведомления о новых устройствах.
- Добавлена потоковая диагностика ping/TCP/DNS/traceroute и загрузочный замер LAN.

- Добавлены Telegram/SMTP/Webhook, очередь с повторными попытками и сохранением
  после перезапуска, внешний heartbeat, формы каналов и журнал доставки.
- Добавлены заметки/история инцидентов, фильтр состояния и экспорт CSV.
- Секреты каналов читаются из окружения или локального `.env.go`; API возвращает
  только имена переменных.

- Добавлены TCP/HTTP(S)/ICMP/DNS/heartbeat-проверки, ограниченный планировщик,
  пакетная запись, агрегаты, создание/закрытие инцидентов и виртуализированный список.
- Пройдены короткие нагрузочные проверки с 50 и 100 HTTP-целями каждые 20 секунд.

- Сохранены восемь исходных макетов, добавлены решения по архитектуре и этапам.
- Создан отдельный Go-каркас: HTTPS, SQLite WAL, миграции, резервные копии, auth/CSRF,
  сессии, роли, настройки, SSE, healthz и завершение по сигналу.
- Новая версия использует отдельные порт 8766, config.go.yaml и runtime/; данные
  Python-версии не мигрируются автоматически.
- Добавлен Preact-интерфейс по токенам макета, локальный Inter, формы входа/setup,
  настройки оформления и пользователей, мобильное меню, пустой экран устройств и 404.
- Добавлены PowerShell-сборка, Makefile, 20 снимков для просмотра и браузерный прогон
  тем, SSE, настроек, пользователей и offline/online без внешних запросов.

### Добавлено

- Репозиторий с ветками main/dev, лицензия MIT и правила исключения частных данных.
- Существующие функции обмена файлами, гостевых ссылок, мониторинга и авторизации.
- Сценарии установки, dev-запуска, smoke-проверки, тестов, линтера и сертификата.
- Dockerfile и Compose с отдельным volume данных и непривилегированным процессом.
- Русский README с пятнадцатью разделами, таблицами конфигурации и FAQ.
- Подробные документы архитектуры, безопасности, API, внешнего доступа и проверки выпуска.
- Четыре воспроизводимых снимка UI: тёмная/светлая темы, десктоп/мобильная ширина.
- API-пример с интерактивным паролем и изолированный HTTP-прогон сессий, CSRF, ролей, чанков, Range и гостевых ссылок.
- Проверки ссылок документации, покрытия конфигурации и приватных файлов в индексе Git.

### Изменено

- Код разделён на backend, frontend, docs и scripts; API-модели вынесены отдельно.
- Пустой tunnel.origin_url теперь использует текущий порт сервера.

### Исправлено

- Очистка сокета Proactor на Windows после WinError 10054: закрытие сокета и снятие транспорта с сервера завершаются даже после сброса подключения клиентом. Остальные исключения сохраняются.
- Добавлены регрессионные проверки очистки транспорта и HTTPS-обрывов, навигации UI и WebSocket; API-прогон также проверяет журнал сервера на ошибки.
- Завершение тестового HTTPS-сервера ожидает дочерний процесс Python на Windows перед очисткой файлов.
- Удалён устаревший patch неиспользуемого импорта из unit-теста после проверки Ruff.

### Проверки и выпуск

- Windows 11 / Python 3.14.4: установка, HTTPS, dev-режим, unit/API/UI, Ruff и скрипты запуска.
- Linux/Docker и реальные испытания большого файла/публичного туннеля ещё не подтверждены; подробности в [протоколе](docs/verification.md).

Версия разработки — 0.1.0-dev.1. Тег v0.1.0 будет создан после выполнения критериев готовности.
