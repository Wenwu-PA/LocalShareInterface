# Журнал изменений

Формат основан на Keep a Changelog; версии следуют SemVer.

## [Unreleased]

### Переход на Go

- Настройки уведомлений и наблюдателя теперь атомарны с аудитом; добавлен
  атомарный аудит тестовых сообщений и заметок к инцидентам.

- Повторены проверки чистого клона, PDF, файлов и 50 мониторов; добавлены
  проверки сохранения логотипа/карточек после перезапуска, позднего ответа графика,
  лимита перекодированного логотипа и запрета branding API в гостевом шлюзе.

- Подготовлен русский словарь и расширяемый переводчик для навигации,
  карточек, статусов и аудита; добавлены тесты резервного языка и подстановок.

- Загрузка и удаление логотипа сети: PNG/JPEG, лимиты 256 КиБ / 512 × 512,
  повторное кодирование без метаданных, атомарный аудит и обновление вкладок.

- Исправлены самопроизвольные SSE-переподключения по HTTP/2: срок записи
  снимается после отправки и больше не обрывает простой между событиями.

- Добавлен порядок карточек обзора: кнопки выше/ниже, серверное сохранение,
  синхронизация открытых вкладок и проверка полного набора без повторений.

- График задержки фильтруется по группе; запоздавшие ответы после смены
  периода не заменяют текущий график, ошибки обновления отображаются явно.

- Повторена проверка чистого клона; дополнительно сверяются PDF-чанки и лицензии.
  Обновлены замеры начальной/полной загрузки frontend и памяти новой сборки.

- Добавлены фоновые размеры папок по индексу с проверкой ACL, ограниченной
  очередью/кэшем, отменой при остановке и обновлением списка/плиток.

- Добавлен отложенно загружаемый PDF-просмотрщик: страницы, масштаб, Range,
  лимит файла 20 МиБ и ограниченный canvas; лицензия PDF.js включена в сборку.

- Дерево папок обновляется после операций, каждые 30 секунд и при возврате
  во вкладку; сохраняет раскрытие/страницу и выходит с опустевшей страницы.

- Изменения устройств и настроек обнаружения теперь атомарны с аудитом;
  ошибка записи журнала откатывает изменение, сводка обновляется через SSE.

- Добавлены фильтр и настройка порядка групп мониторинга, отображение своих
  групп; сводка WAN учитывает все активные проверки и исключает приостановленные.

- Добавлена сводка устройств в обзоре с компактным API, датой сканирования
  и отметкой устаревших данных при ошибке обновления.

- Исправлено применение часового пояса в интерфейсе, добавлены два формата
  даты и обновление открытых журналов при изменении настройки.

- Добавлено перетаскивание в папки списка и дерева: загрузка с компьютера
  и подтверждаемое перемещение выделенных объектов LANBridge.

- Добавлены групповые копирование и перемещение с выбором папки, правила
  конфликтов, последовательная очередь и отчёт об ошибках/остановке.

- Добавлены сочетания клавиш файлового менеджера с подтверждением переноса
  в корзину, поддержкой русской раскладки и сохранением ввода в формах.

- Добавлен выбор стартовой страницы; явные маршруты имеют приоритет,
  старые настройки совместимы и открывают обзор.

- Подключена доставка тревог диска/БД и нормализации через выбранные каналы.
  Состояние и очередь сохраняются атомарно; перезапуск не дублирует неизменную
  тревогу, критический уровень имеет отдельное подавление повторов.

- Добавлены CPU и память процесса: Windows working set/Private commit, Linux RSS;
  карточки показывают интервал CPU и отделяют память процесса от кучи Go.

- Добавлен журнал аудита администратора с фильтрами и курсорными страницами.
  ACL и квоты теперь изменяются атомарно с записью аудита; ошибки SQLite
  файлового API возвращаются как серверные ошибки, заполнение — HTTP 507.

- Проверены сборка и первый запуск Go-версии из чистого локального клона Windows.
  Добавлен воспроизводимый скрипт без сторонних Python-зависимостей; обновлены
  устаревшие сведения о восстановлении БД и службах в инструкции.

- Добавлены смена своего пароля и изменение пароля/роли пользователей администратором,
  проверка текущего пароля, защита последнего администратора и атомарный отзыв
  сессий/гостевых ссылок с записью аудита.

- Добавлен обработчик Windows-службы с корректной остановкой и скриптами
  регистрации под LocalService. Подготовлены systemd unit и отдельная Go-упаковка
  Docker; реальный запуск служб/контейнера ещё не проверен.

- Добавлены предупреждения о свободном месте дисков и лимите SQLite, журнал
  изменений тревоги и карточки БД/WAL/кучи Go в обзоре администратора.

- Добавлено восстановление повреждённой БД из проверенной копии с сохранением
  оригинала. Запуск требует подтверждения и временно ограничен loopback; старые
  сессии/ссылки отзываются, файловые задания не переигрываются, ACL закрываются.

- Ограничены очередь уведомлений (10 000 ожидающих) и история (10 000 / 30 дней).
  Переполнение вытесняет старые задания, сохраняя запись новых инцидентов;
  очистка работает и при выключенных каналах.

- Добавлен лимит основной SQLite `database.max_mb` (512 МиБ), повторное применение
  PRAGMA при смене соединения и понятный HTTP 507 при заполнении БД/диска.
  Проверено отсутствие повреждения и повторное использование освобождённых страниц.

- Добавлен управляемый Cloudflare Quick Tunnel: отдельный шлюз гостевых ссылок,
  проверки перед включением, закрытие соединений при отключении, ограниченный
  журнал без секретных URL и сравнение WAN/наблюдаемого IP. В Windows дочерний
  процесс завершается вместе с сервером. Реальная публикация ещё не проверена.

- Добавлены гостевые ссылки на файлы и ZIP папок: срок, Argon2id-пароль,
  атомарный лимит скачиваний, отзыв и проверка текущих прав владельца.
- Добавлены гостевая страница, список ссылок, отдельные записи гостевых передач
  и локальная генерация QR для ссылки или подключения телефона. Миграция SQLite 6.

- Добавлен массовый перенос выбранных файлов и папок в корзину: подтверждение,
  прогресс, остановка после текущего запроса и отчёт об ошибках. Выбранные потомки
  папок исключаются из повторной обработки. Проверены перенос и восстановление.

- Добавлен выбор/снятие диапазона через Shift + клик по чекбоксам в списке и плитках.
  Диапазон учитывает загруженные невидимые строки и лимит 1000 объектов.

- В историю добавлены приблизительная длительность и средняя скорость с учётом
  пауз. Для недостаточной точности времени и обратного хода часов скорость скрыта.

- В журнале передач отображаются имена пользователей; добавлены поиск по имени
  и фильтр загрузок, скачиваний файлов и ZIP.

- В историю передач добавлены ZIP-скачивания с размером ответа и статусом.
  HEAD не создаёт архив и не расходует одноразовую ссылку.

- В историю добавлены обычные скачивания: объём ответа, статус полной/частичной
  передачи и обнаруженного обрыва. Проверены полный ответ и HTTP Range.

- Добавлен журнал последних 200 завершённых загрузок: поиск, страницы по 25,
  ручное обновление и загрузка данных только при раскрытии панели.

- Добавлено раскрываемое дерево папок: загрузка по требованию, страницы по 50,
  проверка прав до пагинации, сворачивание панели и мобильная компоновка.
- Исправлена гонка сброса прокрутки при переключении списка на плитки.

- Добавлены выбор загруженных файлов и снятие выбора для ZIP, ограничение в
  1000 объектов и сообщение при превышении допустимого объёма списка имён.
- После обновления списка удаляются отметки отсутствующих в нём объектов.

- Добавлен выбор направления сортировки файлов; папки остаются первыми.
  Браузерный тест проверяет оба направления по размеру.

- Вид файлов сохраняется в браузере отдельно для каждой учётной записи.
  Проверено восстановление списка и плиток после перезагрузки.

- Добавлен виртуализированный плиточный вид файлов с адаптивными колонками.
  Проверены переключение и прокрутка 1104 объектов на desktop/mobile.

- Добавлен предпросмотр текста (до 64 КиБ), изображений и видео без новых зависимостей.
  HTML отображается как текст; браузерный тест проверяет ограничение объёма.

- Добавлена форма настройки квот, резерва диска, корзины и срока докачки.
  Проверены сохранение после перезагрузки и отклонение недопустимого резерва.

- Добавлены файловый индекс, папки, поиск, виртуализированный список, потоковые
  загрузки с докачкой/SHA-256, Range, ZIP, копирование, перемещение и корзина.
- Добавлены квоты, наследуемые права, журнал восстановления и очистка временных
  данных. Закрыт обход прав через регистр имени каталога в Windows.
- Добавлены файловые API/модульные тесты и браузерный прогон на 1104 объектах.
- Пройдена передача 20 ГиБ с принудительным перезапуском, докачкой и сравнением
  SHA-256 после полного скачивания; записаны отдельные показатели working set и Private Bytes.


- Добавлены ограниченное ICMP/ARP/mDNS-обнаружение IPv4-устройств, расписание,
  отмена, имена/значки, история присутствия и уведомления о новых устройствах.
- Добавлена потоковая диагностика ping/TCP/DNS/traceroute и загрузочный замер LAN.

- Добавлены Telegram/SMTP/Webhook, очередь с повторными попытками и сохранением
  после перезапуска, внешний heartbeat, формы каналов и журнал доставки.
- Добавлены заметки/история инцидентов, фильтр состояния и экспорт CSV.
- Секреты каналов читаются из окружения или локального `.env.go`; API возвращает
  только имена переменных.

- Добавлены TCP/HTTP(S)/ICMP/DNS/heartbeat-проверки, ограниченный планировщик,
  пакетная запись, агрегаты, создание/закрытие инцидентов и виртуализированный список.
- Пройдены короткие нагрузочные проверки с 50 и 100 HTTP-целями каждые 20 секунд.

- Сохранены восемь исходных макетов, добавлены решения по архитектуре и этапам.
- Создан отдельный Go-каркас: HTTPS, SQLite WAL, миграции, резервные копии, auth/CSRF,
  сессии, роли, настройки, SSE, healthz и завершение по сигналу.
- Новая версия использует отдельные порт 8766, config.go.yaml и runtime/; данные
  Python-версии не мигрируются автоматически.
- Добавлен Preact-интерфейс по токенам макета, локальный Inter, формы входа/setup,
  настройки оформления и пользователей, мобильное меню, пустой экран устройств и 404.
- Добавлены PowerShell-сборка, Makefile, 20 снимков для просмотра и браузерный прогон
  тем, SSE, настроек, пользователей и offline/online без внешних запросов.

### Добавлено

- Репозиторий с ветками main/dev, лицензия MIT и правила исключения частных данных.
- Существующие функции обмена файлами, гостевых ссылок, мониторинга и авторизации.
- Сценарии установки, dev-запуска, smoke-проверки, тестов, линтера и сертификата.
- Dockerfile и Compose с отдельным volume данных и непривилегированным процессом.
- Русский README с пятнадцатью разделами, таблицами конфигурации и FAQ.
- Подробные документы архитектуры, безопасности, API, внешнего доступа и проверки выпуска.
- Четыре воспроизводимых снимка UI: тёмная/светлая темы, десктоп/мобильная ширина.
- API-пример с интерактивным паролем и изолированный HTTP-прогон сессий, CSRF, ролей, чанков, Range и гостевых ссылок.
- Проверки ссылок документации, покрытия конфигурации и приватных файлов в индексе Git.

### Изменено

- Код разделён на backend, frontend, docs и scripts; API-модели вынесены отдельно.
- Пустой tunnel.origin_url теперь использует текущий порт сервера.

### Исправлено

- Очистка сокета Proactor на Windows после WinError 10054: закрытие сокета и снятие транспорта с сервера завершаются даже после сброса подключения клиентом. Остальные исключения сохраняются.
- Добавлены регрессионные проверки очистки транспорта и HTTPS-обрывов, навигации UI и WebSocket; API-прогон также проверяет журнал сервера на ошибки.
- Завершение тестового HTTPS-сервера ожидает дочерний процесс Python на Windows перед очисткой файлов.
- Удалён устаревший patch неиспользуемого импорта из unit-теста после проверки Ruff.

### Проверки и выпуск

- Windows 11 / Python 3.14.4: установка, HTTPS, dev-режим, unit/API/UI, Ruff и скрипты запуска.
- Linux/Docker и реальные испытания большого файла/публичного туннеля ещё не подтверждены; подробности в [протоколе](docs/verification.md).

Версия разработки — 0.1.0-dev.1. Тег v0.1.0 будет создан после выполнения критериев готовности.
